# White Room question-bank source imports

Source photos are kept in staging folders and are not yet live, searchable questions.

- `gce-photos/`: set 01, 33 images from `past papers resources.zip`.
- `gce-photos-set-02/`: set 02, 33 images from `past papers resources(1).zip`.

Each set has a `manifest.json` with image hashes and provisional metadata. Extracted questions should only be added to the live question bank after transcription and source metadata are checked against the images.
