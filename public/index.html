    Lesson Publisher

    Prepare a lesson deployment bundle from finished White Room lesson JSON files.

    Upload lesson ZIP

    Choose a ZIP containing either an index.json manifest and lesson JSON files, or complete section-based chemistry documents with their SVG figures. The publisher checks them, merges them with the live lesson index, and downloads a patch ZIP. It does not publish to Firebase; extract the patch into your project, validate, then deploy as usual.

    Before deploying

    1. Extract the downloaded patch into the project root, allowing it to replace public/content/lessons/index.json.
    2. Run npm run validate from the project folder.
    3. If validation passes, deploy the project to Firebase using your existing deployment process.

    The browser only creates a local download. No Gemini API call is made, no API key is used, and no live files are changed by this page. Section-based reference documents save completion on this device only and do not award XP.
